# Introduction

Tessera is a copy-paste React component library built with **Tailwind CSS v4**, **Radix primitives**, and **Motion**. Instead of hiding markup inside an opaque npm dependency, every component lands directly in your repository as editable TypeScript so both you and your AI coding tools can read, extend, and ship it cleanly.

<DocsCards />

## Core Principles

1. **Source ownership** — Components are copied directly into `components/tessera/` via the shadcn registry. No version lock-in, no wrapper workarounds.
2. **Engineered motion** — Compositor-only `transform` and `opacity` transitions, Apple-style spring physics where interactions benefit, and `prefers-reduced-motion` support by default.
3. **Tailwind v4 native** — Semantic CSS variables and standard utility classes with zero proprietary styling runtime.
4. **AI-readable architecture** — Flat file structure and explicit TypeScript prop interfaces designed to be understood by coding agents in a single pass.

## Quick Start

Initialize the shadcn registry in your project, then pull components directly as you build:

```bash
npx shadcn@latest add https://tessera.ui/r/<component>.json
```

Continue to the [Installation guide](/docs/installation) for setup instructions and registry structure.
