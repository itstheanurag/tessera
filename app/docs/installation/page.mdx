# Installation

Tessera components are distributed via the shadcn registry so they land directly inside your repository as editable TypeScript files.

## CLI

Add a component directly using the shadcn CLI:

```bash
npx shadcn@latest add https://tessera.ui/r/<component>.json
```

## Manual Installation

If you prefer, you can browse the [documentation](/docs) and copy the component source files manually into your `components/tessera` directory.
